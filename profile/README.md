# Rough Stack

Rough Stack is an open-source platform for learning systems engineering by
implementing real storage, scheduling, networking, and reliability mechanisms.

The project is organized by responsibility:

- [`web-platform`](https://github.com/roughstack/web-platform) provides the
  educational interface, accounts, discussions, submissions, and control plane.
- [`execution-runtime`](https://github.com/roughstack/execution-runtime) provides
  the execution protocol, language SDKs, runners, and conformance tests.
- [`challenges`](https://github.com/roughstack/challenges) provides public
  statements, contracts, starters, deterministic simulations, and public tests.

Official evaluation remains private so hidden workloads and calibration data do
not enter public build contexts.

The repositories are being prepared for their first public release. Security
boundaries and hosted judging should not be considered production-ready until the
published readiness gates are complete.
