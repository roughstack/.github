# Security policy

Use GitHub's private vulnerability reporting for the affected Rough Stack
repository. Do not open a public issue containing exploit details.

Reports involving sandbox escape, secret exposure, authentication bypass, result
forgery, queue corruption, denial of service, path traversal, or private-evaluation
leakage should include the affected revision, impact, and minimal reproduction.

The project is still under active hardening. Public official judging remains
disabled until the documented sandbox and operational reviews are complete.
